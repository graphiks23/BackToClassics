# Back To Classics

A mod that recreates many of the old aspects of Brawl Stars


# Building
## UI
Go to UI folder, then open startup.fla to compile ui patches

## Brawl Pass
Open vault_pass.fla in Brawl Pass folder to compile Brawl Pass patches

## Buddy
Open buddy 60fps.fla in Buddy folder to compile buddy patches

## BTC Custom assets
Open !publish.fla in btc assets folder to compile btc assets
