# Back To Classics

A mod that recreates many of the old aspects of Brawl Stars


# Building
To build this mod, you will need to have Adobe Animate 2022 or 2023, and [SupercellSWF-Animate](https://github.com/sc-workshop/SupercellSWF-Animate) plugin to export to `.sc`.
>[!IMPORTANT]
>Adobe Animate 2024 does not have proper 9-slice support, so any symbol with 9-slice needs to be manually converted to fills

> [!NOTE]
> You may need to fetch Brawl Stars 68.250 assets to apply these patches.

## UI  
 - Go to UI folder, then open `!Publish.fla` to compile ui patches

## Brawl Pass  
 - Open `!Publish.fla` in brawl pass folder to compile Brawl Pass patches

## Buddy  
- Open `!Publish.fla` in Buddy folder to compile buddy patches

## BTC Custom assets
  - Shop assets
    - Open `Publish shop.fla` in btc assets folder to compile

## Hero portraits  
- Open `hero_portaits.fla` in hero portraits folder to compile

## Loading  
 - Open `loading.fla` in loading folder to compile the custom loading screen

## Profile  
 - Open any of the fla's in profile folder to compile a wip version of the profile

## Shop  
 - Open `Publish shop.fla` in shop folder to compile

## Daily Wins  
 - Open `!Publish.fla` in daily wins folder to compile
